# No Raw Emojis Rule

- **Strict Guideline**: Never use raw text emojis (e.g. 🔴, 🟡, 🟢, ⚠️, 🌙, etc.) anywhere in the UI layout, status chips, badges, option dropdowns, or modals.
- **Icon Standard**: Always use Lucide React icons (`lucide-react`) (such as `<CheckCircle2 />`, `<AlertTriangle />`, `<Clock />`, `<AlertCircle />`, `<Info />`, `<XCircle />`, etc.) with cohesive Tailwind text color utilities for visual indicators.
